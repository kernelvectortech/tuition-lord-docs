# Tuition Lord — App Idea

*(Note: an app with a similar genre already exists — see comparison at the end)*

## Built for real situations
- Made to be used while walking, standing in a bus, on stairs, holding an umbrella in the rain
- Every action is one tap, nothing complicated to read or type
- Fast enough to use in a hurry, without needing full attention

## Problem
Tutors track tuition days by memory or by hand. It's easy to lose count, forget a cancelled class, or forget to log a day. Payment is usually based on a fixed number of days (e.g. 12 days = 1 month), and sometimes tuition ends early, so payment needs to match whatever days were actually held.

## Who it's for
Home tutors.

## How it works
- Open the app, no login needed
- Add a student — just name and monthly rate, rest is optional
- Tap "Mark Today" after each class — one tap
- Can also pick Yesterday, Tomorrow, or a date from calendar — nothing auto-filled
- If a scheduled class gets cancelled, mark it as "not held" so the count stays correct
- Get a notification asking "Was today's class held?" for scheduled days — so a cancelled class never stays wrongly marked or forgotten
- See a simple counter: days done out of the cycle, and amount due so far
- Settle payment anytime — full cycle or partial (if tuition ends early) — counter resets after
- Student/guardian's number is easy to copy-paste, call, or message directly from their page — no need to search for it elsewhere (phone contacts, old messages, etc.)
- Share a quick summary (text or image) with guardian — one tap
- Share a link or QR code so guardian can see the count and payment status, no install needed

## Data storage
- No cloud backup needed — everything stays on the tutor's own phone
- No account, no login, no server dependency
- App works fully even without internet, since data isn't dependent on any cloud

## Design principles
- No login required
- Minimum typing — most actions are one tap
- Nothing counted automatically — always needs a manual confirm
- Works well one-handed, on the go, in a hurry

## Platform
- Android app first
- iOS later

## Cost
- No paid server or hosting needed to start — built entirely on free tools

## Compared to the existing "Tuition Tracker" app
- An app with this name already exists on Android and iOS (10K+ downloads)
- It needs Gmail login to back up data, and reviews mention it can lose older months' data
- It requires manually "starting a new month" instead of automatic cycle tracking
- It doesn't clearly separate a cancelled class from a held one
- Tuition Lord fixes these: no login needed, automatic cycle and payment calculation, clear cancel-vs-held tracking, and guardian access via link/QR without installing anything
